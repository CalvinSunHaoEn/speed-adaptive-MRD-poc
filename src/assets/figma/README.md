# Figma vector assets

Every file here belongs to a node in Figma frame `480:8550`
("Speed up Icon+STRIP META POC", file `6LyB9UDTJOIJCJPtdoLUnX`).
`../../../tools/assets/manifest.json` is the node-id ↔ filename map, and it also
records each node's box in Figma so an asset can never be swapped in at the
wrong size.

## Status: these are placeholders

The session that built this prototype could not reach `www.figma.com` — the
egress policy on the build environment blocks every Figma host, so the export
URLs the Figma MCP server hands out could not be downloaded. Each file here was
generated by `tools/assets/make-placeholders.mjs` at the node's exact Figma
dimensions, and carries a `data-placeholder="true"` marker.

Layout, timing and the animation rig are therefore correct; the artwork is not.

## Replacing them with the real exports

1. Re-issue the asset URLs from Figma (the MCP `get_design_context` response
   lists them; `download_assets` re-issues them per node). They expire after
   about 7 days.
2. Paste each URL into the matching entry in `tools/assets/manifest.json` as a
   `"url"` field.
3. `npm run fetch:assets`

The fetch script only touches entries that have a `url`, and
`make-placeholders.mjs` never overwrites a file that lacks the placeholder
marker — so a partially-real set is safe to keep working with.

Dropping the SVGs in by hand works too: same filenames, same directory.
